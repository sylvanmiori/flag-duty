# Flag Duty

A route planner for school band flag fundraisers. Photograph the paper address
sheet (or paste/type the addresses), check the list, and Flag Duty geocodes
every address and works out the fastest driving order. In the truck, a big
Next Stop card hands off to Google Maps for turn-by-turn and checks off each
stop as flags are placed or collected. Routes and check-offs are saved on each
phone; no account, no API keys.

The whole app is the single file `index.html` in this repo. Host it anywhere
static files can live, or just open the file in a browser.
